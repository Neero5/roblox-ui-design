# L01 Genshin UI templates (InochiPM)

**Owner, 2026-11-10:** "I honestly quite like the UI look of AAA games like genshin. One example could be" (this sheet). Clip 07 (rated 5) moves in the same manner.
**Owner's rating, 2026-11-10:** 4.5, "purely because it cannot fit on most *roblox* game type, but doesn't stop being great and unique". **No benchmark:** the owner set none (Genshin is not a benchmark in any profile).
**Use:** principles only (core I4). Never its art, logo, icon set, card shapes or exact layouts.

## What is on the sheet
- **Character menu, six tabs** (Attributes, Weapons, Artifacts, Constellation, Talents, Profile): a left text list with a small diamond marking the chosen tab; a top bar with the element icon and a breadcrumb, a row of round party portraits, the currency and a round close button; the centre left EMPTY for the 3D character; a narrow right column of detail (name, level, stars, stat rows, short text); ONE pale pill button bottom right ("Ascend", "Switch", "Enhance"). The backdrop is a dark starfield that changes hue with the tab (purple for Constellation), never the layout.
- **Wish banner:** one large illustrated card, the title on an angled ribbon, the odds in small text, two pill buttons bottom right with their costs, banner thumbnails as tabs on top.
- **Wish result:** ten tall crystal cards in a row; the best one lit gold.
- **Item cards (artifact, weapon):** a tall portrait card; a header band coloured by rarity (gold 5-star, purple 4-star) carrying the game's mark; a round medallion with the item centred; a cream paper body; the name in a large serif, a star row, a small type pill, stat rows (label left, value right), small coloured section headings ("Name of Effect", "Ascension Materials", "How to Obtain") over muted body text; an artifact set listed as small icon + name rows.
- **Two blank card frames** (a stacked pair with a purple face, a cream scalloped frame).

## Why it works (principles)
1. **Two surfaces for the whole game.** Dark translucent space for menus, cream paper for item cards. Every screen uses one of the two; nothing else.
2. **Rarity is a colour SYSTEM, not decoration.** Gold and purple appear only where rarity is information (card band, star row, the lit result card). Everything else is neutral, so rarity reads instantly (matches the premium profile's "rarity colours are information").
3. **The hero owns the centre.** The character or the item medallion takes the middle; text hugs a left list and a right column; the space between is left empty on purpose (R8).
4. **Fixed anchors in fixed places.** Top bar (party, currency, close), left tab list and the bottom-right primary button sit in the same spot on every tab. Only the right column and the backdrop hue change (R6; clip 07 moves the same way).
5. **One primary action, always in the same corner.** A pale pill, bottom right. Secondary buttons beside it are quieter.
6. **Type does the work.** A large serif name, small caps or small headings, muted body text, numbers right-aligned in stat rows (R9). Very few boxes.
7. **One ornament family.** Hairline diamonds, arcs, compass stars and thin frame lines, used everywhere and always quiet. No ornament from outside the family (I1, R10).
8. **Generous emptiness.** Large calm areas around small, crisp content: the screen looks expensive because it is not filled.

## Weak or risky
- Small, low-contrast body text on the dark screens (R13 would object at Roblox sizes; Roblox players often play on small windows and phones).
- Lorem ipsum and "?????" are template placeholders (fine for a template, a fail if shipped: R12).
- Copying this look outright makes a game read as "a Genshin clone" (I2 and I4): borrow the principles, build the identity from the game's own world.

## Layout rules (adopted by the owner 2026-11-10: "Adopt L1 to L7")
| # | Proposed rule | Evidence |
|---|---|---|
| L1 | Two surfaces at most for the whole UI (for example a menu surface and a card surface), both from the game's identity. | L01, 07 |
| L2 | Rarity or tier colours form one system and appear only where they carry information; the rest of the UI stays neutral. | L01, 07, premium profile |
| L3 | The hero owns the centre; text sits in side columns; the space between stays empty. | L01, 07, 04 |
| L4 | Anchors (top bar, tab list, primary button) stay in the same place on every tab of a screen; a tab changes only its content (and at most the backdrop's hue). | L01, 07 |
| L5 | One primary action per screen, in the same position on every screen of the game. | L01 |
| L6 | One ornament family (a few motifs, one line weight), quiet everywhere. | L01, 03 |
| L7 | Leave calm empty space: content density goes down as the importance of the screen goes up. | L01, 04 |
