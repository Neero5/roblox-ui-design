# Reference library: rated UI frames to aim at

Rated frame sheets, tagged so a task opens only one to three that match. Paths are from the plugin root (two folders up from this skill's `SKILL.md`). Open with the Read tool; take principles (hierarchy, anchors, spacing, timing, type, material), never art or layouts (I4).

## How to use (Mode A)
1. Match the screen type (menu hub, shop or inventory, title or flow screen, reward), then the mood the game's profile names.
2. Open one to three sheets; add one line each to the brief: "from <id>: take ...; avoid ...".
3. At the check, put the resting capture beside the reference and name the three biggest gaps (hierarchy, spacing, anchors, type, material, selected state).
