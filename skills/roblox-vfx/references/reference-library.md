# Reference library: rated frames to aim at

Frame sheets from clips the owner rated, tagged so a task loads only the few that match. Paths are from the plugin root (two folders up from this skill's `SKILL.md`): open the image with the Read tool, look at it, then write what you take from it. Never copy art (I4): take timing, shape language, value structure and layering.

## How to use (part of Mode A, every time)
1. Match in this order: **tier** (frequent or rare), then **effect type**, then **element or hue**. Prefer rating 4.5 or more.
2. Pick **one to three** sheets. Never load the whole library.
3. Open them. In the brief, add one line per reference: "from <id>: take <timing / shape / layering / value>; avoid <what lost points>".
4. At the check, put the build's peak capture beside the chosen reference and name the **three biggest gaps** (shape, brightness and contrast at the core, layering, detail, size, colour). Fix the largest one or two; report the rest.
5. No match? Say so, and ask the owner for a reference before building a rare or showcase effect.
